# Pairwise AI

Blind, pairwise model comparison. Two anonymous answers, you vote, then the names appear.

```bash
npm install
npm run dev       # http://localhost:3000 (mock data)
npm run preview   # single-file HTML preview in preview/dist/
```

Set `NEXT_PUBLIC_API_URL` to point at the FastAPI backend. Everything else is in [handoff.md](handoff.md).
